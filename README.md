# BitLab Website

Static HTML/CSS/JavaScript website for BitLab.

## Local development
Open the folder in VS Code and use Live Server.

## Current hero
The hero uses a CSS/JavaScript calendar-page style phrase animation. No video or framework is required.

## Deployment
GitHub → Railway → bitlabhq.com


V3 design notes: the hero phrase now uses a fixed-width page so the calendar transition stays visually stable. The long “take your shop online” hero phrase was removed for now. The palette uses the original violet/pink values directly with reduced blur and transparency for a sharper, more vibrant look.
